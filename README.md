# 口语小站 · Phase 1 静态原型

面向大学英语专业、口语偏弱的小白学习者。暖色、手机友好、界面中文 / 练习内容英文。

## 如何本地打开

**方式 A（最简单）**  
用浏览器直接打开本目录下的 `index.html`：

- macOS：双击，或拖到 Chrome / Safari  
- Windows：右键 → 打开方式 → Chrome  
- 或在地址栏输入文件路径

**方式 B（推荐，避免部分浏览器限制麦克风）**

```bash
cd english-practice-site
python3 -m http.server 8765
```

浏览器打开：http://127.0.0.1:8765/

手机同一 Wi-Fi 时，可用电脑局域网 IP 访问（需先启动上面的服务）。

## 页面一览

| Hash | 页面 | 功能 |
|------|------|------|
| `#home` | 今日打卡 | 连续天数、4 任务勾选、进度、今晚磨耳朵 B 站链接 |
| `#path` | 学习路径 | 四阶段锁定/解锁 + BBC/VOA/Oxford 等资源 |
| `#pronounce` | 练发音 | IPA 提示、语音合成原音、MediaRecorder 录音对比 |
| `#chat` | 对话练习 | 教练 **ee** 聊天 UI + 预设温和纠正 |
| `#knowledge` | 知识+英语 | 细胞 / LLM / Python 三步微课 |
| `#review` | 错音本 | Again / Hard / Good 间隔复习样式 |

## 哪些是模拟（Mock），哪些是真的

| 能力 | 状态 |
|------|------|
| 打卡、连续天数、错音本 | ✅ 真 · `localStorage` 持久化 |
| 学习路径资源链接 | ✅ 真 · 外链可点 |
| B 站磨耳朵链接 | ✅ 真 · 手机浏览器打开 B 站 |
| 播放「原音」 | ✅ 真 · Web Speech Synthesis（需浏览器支持） |
| 录音 | ⚠️ 有麦克风权限时用 MediaRecorder；否则走模拟录音 |
| 发音得分 | ❌ 模拟随机分（72–95），非真实音素评分 |
| 教练 ee 回复 | ❌ 关键词匹配的预设话术，非真实大模型 |
| 阶段解锁 | ⚠️ 演示按钮可手动解锁，非按真实进度自动 |

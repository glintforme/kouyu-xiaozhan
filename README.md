# 口语小站 · Phase 1 静态原型

面向大学英语专业、口语偏弱的小白学习者。暖色、手机友好。

**线上地址：** https://glintforme.github.io/kouyu-xiaozhan/

## 多档案存储（哥哥 / 妹妹互不干扰）

- 默认两个档案：**妹妹**、**哥哥**，可改名、可新建。
- 每个档案的打卡、错音本、复述、路径进度**分开存**在本机 `localStorage`。
- **同一浏览器**里必须点切换按钮换档案；否则会写进当前档案。
- 换手机/电脑：当前档案 →「导出」JSON → 另一设备「导入」（可覆盖或新建）。
- **不需要账号**；数据默认不上传云端。

## 本地打开

```bash
cd english-practice-site
python3 -m http.server 8765
# http://127.0.0.1:8765/
```

或直接打开 `index.html`。

## 页面

| Hash | 功能 |
|------|------|
| `#home` | 档案切换、打卡、今日单词预览、磨耳朵 |
| `#vocab` | 词汇本（每词独立中文释义） |
| `#pronounce` | IPA + 释义 + 录音对比 |
| `#chat` | 教练 ee 预设对话 |
| `#knowledge` | 知识微课三步走 |
| `#review` | 错音本翻面复习 |
| `#path` | 四阶段路径 |

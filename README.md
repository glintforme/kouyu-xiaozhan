# 口语小站 · 游戏化双端（v5）

线上地址：**https://glintforme.github.io/kouyu-xiaozhan/?v=5**

妹妹免登录练口语打卡升级；哥哥用密码进管理端看进度、偶尔发任务。教练 **ee** 每天自动布置任务（静态站本地 JS 生成）。

> 当前仍在迭代，**暂未正式交给妹妹使用**。

## 谁用哪个入口

| 角色 | 怎么进 | 做什么 |
|------|--------|--------|
| **妹妹（主用户）** | 直接打开链接，默认学习端 `#home` | 做任务拿 XP、挑战测验、练发音/词汇/对话/微课 |
| **哥哥** | 右上角「管理」或「更多 → 哥哥管理端」→ 确认 → `#admin` | 首次设置密码 → 账号 `brother` + 密码；看板、发任务、导入同步包 |

## v5 本轮更新

- **移动端**：底部 5 主入口 +「更多」抽屉；管理入口二次确认；加载态 / Toast / 触控热区；XP 进度条动效
- **内容加厚**：8 个词汇主题（各词独立中文释义）；发音条目扩充；对话快捷句与教练回复加多；周/月/半年/年测题库加厚（约 10–12 题/场）
- **奖励**：徽章墙显示解锁条件；进度页提示下一枚可冲徽章；完成任务反馈连续天数 / XP / 升级

## 同步限制（重要）

本站部署在 **GitHub Pages 静态托管**，没有服务器账号云同步。

- **同一手机/浏览器**：管理端可直接读取本机「妹妹」档案。
- **不同设备**：妹妹点「导出同步码 / 进度」→ 把 JSON 发给哥哥 → 哥哥在管理端「导入她的进度」。
- 数据存在浏览器 `localStorage`，清缓存会丢，请定期导出。

## 管理密码（家庭演示级）

- 首次进入管理端时**自行设置密码**（至少 4 位）。
- 账号固定为 **`brother`**。
- 密码以 **随机盐 + SHA-256**（Web Crypto）存在本机 `localStorage`，**不是**银行级安全。
- **请勿使用银行卡 / 邮箱等重要密码。**

## 游戏循环

- **任务**：ee 每日自动 4 条 + 可选周测任务；哥哥可额外发布。
- **XP / 等级**：每 100 XP 升 1 级。
- **挑战**：周测 / 月测 / 半年测 / 年测（词汇释义 + 发音概念 + 对话），通过率 ≥ 60% 拿满奖励与徽章。

## 延后（仅文档，本轮未做后端）

### 云同步（下一阶段）

可选方案（需另选其一再开发）：

1. **轻量后端**（Cloudflare Workers / Vercel + KV/D1）：妹妹账号登录，进度存云端，哥哥管理端只读。
2. **Firebase / Supabase**：Auth + Realtime DB，跨设备自动同步。
3. **继续静态 + 加强导出**：二维码/剪贴板一键同步码（仍需手动）。

推荐家庭场景：方案 1 或 2，并加「妹妹学习账号 / 哥哥管理账号」分离。

### 真实 ee API（下一阶段）

见 `js/game.js` 里 `EE_CONFIG`：

- 当前：`mode: "local-auto"`（按日期本地生成任务）。
- 升级：改 `mode: "api"`，填 `apiEndpoint`，在 `fetchEeTasks` 接认证；由 Grok Bot / ee 按学习进度动态发任务与纠音对话。
- 对话页目前为关键词预设回复；接 API 后可换成真实教练对话。

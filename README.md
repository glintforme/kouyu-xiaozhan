# 口语小站 · 游戏化双端（v4）

线上地址：**https://glintforme.github.io/kouyu-xiaozhan/**

妹妹免登录练口语打卡升级；哥哥用密码进管理端看进度、偶尔发任务。教练 **ee** 每天自动布置任务（静态站本地 JS 生成；可接真实 API）。

## 谁用哪个入口

| 角色 | 怎么进 | 做什么 |
|------|--------|--------|
| **妹妹（主用户）** | 直接打开链接，默认学习端 `#home` | 做任务拿 XP、挑战测验、练发音/词汇/对话/微课 |
| **哥哥** | 右上角 🔐 或打开 `#admin` | 首次设置密码 → 之后账号 `brother` + 密码登录；看板、发任务、导入同步包 |

## 同步限制（重要）

本站部署在 **GitHub Pages 静态托管**，没有服务器账号云同步。

- **同一手机/浏览器**：管理端可直接读取本机「妹妹」档案。
- **不同设备**：妹妹点「导出同步码 / 进度」→ 把 JSON 发给哥哥 → 哥哥在管理端「导入她的进度」。
- 数据存在浏览器 `localStorage`，清缓存会丢，请定期导出。

## 管理密码（家庭演示级）

- 首次进入管理端时**自行设置密码**（至少 4 位）。
- 账号固定为 **`brother`**。
- 密码以 **随机盐 + SHA-256**（Web Crypto）存在本机 `localStorage`，**不是**银行级安全。
- **请勿使用银行卡 / 邮箱等重要密码。** 仅适合家人玩具级站点。
- 改密：管理端底部「修改密码」。

## 游戏循环

- **任务**：ee 每日自动 4 条 + 可选周测任务；哥哥可额外发布。
- **XP / 等级**：每 100 XP 升 1 级；完成任务与测验获奖。
- **挑战**：周测 / 月测 / 半年测 / 年测（词汇释义 + 发音概念 + 对话），通过率 ≥ 60% 拿满奖励与徽章。
- **ee 接入**：见 `js/game.js` 里 `EE_CONFIG`（`mode: "local-auto"`；以后可改 `api` + `apiEndpoint`）。
